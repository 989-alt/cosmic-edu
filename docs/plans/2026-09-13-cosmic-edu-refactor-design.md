### UI/UX 실측
- 계절별 남중 고도: 절대 위치 오버레이 7개(프리셋·시점 토글·미니맵·월별 차트·InfoPanel·슬라이더·재생 HUD)가 겹침. 차트가 미니맵과 퀴즈 버튼을 덮고 태양 궤적은 상단이 잘림.
- 하루 태양 고도: drei `Html` 방위 라벨이 그래프 패널·슬라이더 밑에 깔림. 9:30에 태양이 화면 밖.
- 자전축: 기본 상태에서 지구가 InfoPanel 뒤에 숨음(궤도 x=+20).
- 공통: 하단 슬라이더 패널이 모듈마다 인라인 스타일로 5벌 복제. 오버레이 충돌 관리 없음.
- WebGL Context Lost(이전 세션 메모)는 이번 실측에서 재현되지 않음. 범위 밖.

## 1. 결정 사항
- 주 사용 환경: 교사 시연(TV·빔)과 학생 태블릿 둘 다 지원. 반응형.
- 표현 방식: 6-2 하루 태양 고도·에너지 밀도는 2D SVG, 계절별 남중 고도·자전축은 3D 유지(카메라 프리셋 고정).
- 범위: 정비(버그·공용 레이아웃·인프라)는 전 모듈, 재설계는 6-2만. 4학년·6-1 장면은 무접촉.

## 2. 공용 레이아웃 `SimLayout`

```
┌ header ─────────────────────────────┐
│ tabs (sub-module nav)               │
├──────────────────────┬──────────────┤
│  Stage (2D/3D)       │  Inspector   │  데스크톱: 우측 320px 고정
│  full-bleed          │  (수치·설명· │  태블릿(<900px): 하단 시트
│ ┌ HUD chips ┐        │   차트)      │
├─┴───────────┴────────┴──────────────┤
│ Dock: [▶][×1] ──슬라이더── [프리셋]   │  항상 보임, 72px
└─────────────────────────────────────┘
```

- **Stage**: 2D SVG든 R3F Canvas든 여기에만 그린다. `--stage-inset-right`, `--stage-inset-bottom` CSS 변수로 안전영역을 노출하고 3D 라벨은 이 영역을 피한다. 카메라 프리셋과 회전 제한은 Stage가 소유한다.
- **Dock**: 현재 5벌 복제된 하단 슬라이더를 흡수. 슬롯 `play / speed / slider(라벨·눈금) / presets`. 태블릿에서는 프리셋이 슬라이더 위 칩 행으로 접힌다.
- **Inspector**: InfoPanel 후신. 섹션 탭(`수치 | 설명 | 그래프`). 미니맵·월별 차트처럼 Stage 위에 떠 있던 것은 전부 여기로 들어간다.
- **HUD chips**: 실시간 수치 3~4개. Stage 좌상단 한 줄. 그 이상은 Inspector.
- **상태**: 전역 `timeValue` 공유 제거. 6-2 네 탭은 `useSeasonStore { month }` 하나만 공유한다.
- 반응형 기준점은 900px 하나. 터치 타깃 44px, 슬라이더 트랙 12px.

원칙: 오버레이 충돌은 z-index 조정이 아니라 "떠 있는 것"을 없애서 푼다.

## 3. 6-2 네 모듈

공유 상태 `useSeasonStore { month: 1..12 }`. 모든 계산은 `src/utils/solar.ts` 순수 함수에서 받는다.

### ① 하루 태양 고도 → 2D SVG 측면 도해
- 관측자가 남쪽을 보는 교과서 그림. 지평선, 동(좌)→남(중앙 위)→서(우) 태양 호, 중앙 막대(1m), 그림자.
- 데이터 테이블 6점 폐기. `sunAltitude(lat, decl(month), hourAngle(hour))`로 일출~일몰 전 구간 계산. 위치·수치·그림자 불일치가 구조적으로 사라진다.
- Dock 슬라이더 = 시각(일출~일몰). Inspector 그래프 탭 = 고도·그림자 길이 곡선.

### ② 에너지 밀도 → 2D SVG
- 평행 광선 다발(폭 고정) + 바닥 선분. 고도에 따라 바닥 구간이 `1/sin`으로 늘어난다.
- 지구 텍스처 바닥 폐기. 바닥 구간을 색 온도(빨강~파랑)로 칠한다.
- Dock 슬라이더 = 고도. 프리셋 = 하지·춘추분·동지(37°N 값, `month`와 연동).

### ③ 계절별 남중 고도 → 3D 유지, 관측자 시점만
- 우주 시점 탭은 ④로 이관(중복 제거). 카메라 프리셋 `observer-south`, 수평 회전 ±60°, 상하 고정.
- 태양 호를 남쪽으로 기울여 그린다(현재는 수직 반원 = 적도 관측자). 하지·동지 호는 고스트, 현재 월만 실선.
- 미니맵·월별 낮 길이 차트는 Inspector 탭으로.

### ④ 자전축 임팩트 → 3D 유지, 공전 위상 수정
- 자전축은 월드 고정 `rotation=[0,0,+tilt]`(−x 방향). 이 규약에서 6월을 `θ=0`(+x)에 둔다: `orbitAngle(month) = (month−6)/12·2π`. `subsolarLatitude(month) = tilt·sin((month−3)/12·2π)`.
- 카메라 프리셋 `orbit-oblique`. Inspector 안전영역을 반영해 지구가 항상 화면 안.
- 공전 위치 슬라이더 = `month`(공유 상태). 전역 `timeValue` 사용 중단.

핵심: 지금은 세 모듈이 각자 다른 상수(76/76.5/데이터 6점)를 들고 있어 탭마다 숫자가 미묘하게 다르다. 공식 하나로 통일하면 ①②③④가 `month` 하나로 자동 정합된다.

## 4. 검증

- `solar.ts` vitest: 37°N 하지 남중 76.4°, 동지 29.6°, 춘분 53°, 낮 길이 하지 14.5h·동지 9.5h, 춘분 일출 정동, 공전각 규약(6월에 축이 태양을 향함).
- `moon.ts` vitest: 3·7·10·15·22·25일에서 (x=±0.7, y=0) 명암 판정. 이번에 배포된 버그가 이 검사에서 바로 잡힌다.
- `MoonPhase2D`는 `isLitAt`로 픽셀 단위 판정만 하고 그린다. Canvas 호 방향 플래그를 코드에서 없앤다.
- Playwright: 뷰포트 1366×800, 820×1180에서 (a) 달 픽셀 검사, (b) 자전축 모듈 지구가 Inspector와 겹치지 않음.

## 5. 실행 순서
1. 핫픽스: 달 위상 커밋·push, `vercel.json`.
2. `solar.ts`·`moon.ts` + vitest green.
3. `SimLayout`(Stage/Dock/Inspector/HUD)을 4학년·6-1에 먼저 적용(장면 무변경).
4. 6-2 ① 2D.
5. 6-2 ② 2D.
6. 6-2 ④ 공전 위상 수정·카메라 프리셋.
7. 6-2 ③ 우주 시점 제거·호 남향·Inspector 이관.
8. Playwright 검사 2종 + 태블릿 실측.

각 단계 게이트: `npm run build` green + 해당 검사 통과.
